# 🗺️ Rota Cultural do Sul da Bahia

Aplicação web interativa desenvolvida para o **Projeto de Extensão II — Programa de Ação e Difusão Cultural** (Bacharelado em Ciência da Computação).

🔗 **Acesse o site:** [https://dominioliveiranascimento.github.io/rota-cultural-sul-da-bahia/](https://dominioliveiranascimento.github.io/rota-cultural-sul-da-bahia/)

## 📌 Sobre o Projeto
Um mapa interativo que percorre a Costa do Cacau e a região grapiúna (**Canavieiras, Una, Itabuna, Ilhéus, Uruçuca/Serra Grande e Itacaré**), apresentando a história, tradições culturais, curiosidades e pontos turísticos de cada localidade para valorizar e difundir a cultura do Sul da Bahia.

## 🚀 Funcionalidades
* Mapa vetorial (SVG) com trajeto animado entre as cidades.
* Navegação por botões (*Anterior* / *Próximo*), clique direto no mapa ou setas do teclado.
* Conteúdo dividido em abas (*História*, *Cultura* e *Pontos Turísticos*).
* Interface responsiva para celular e computador.

## 🛠️ Tecnologias
* HTML5
* CSS3
* JavaScript (Vanilla JS)
